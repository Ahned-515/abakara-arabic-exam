# محتوى الامتحان المطلوب قبل النشر
لا يحتوي المستودع الأصلي على أسئلة أو نص القصة؛ لا توجد أسئلة مُعتمدة ضمن هذا التغيير.
جهّز ملف JSON من 20 سؤالًا، مجموعها 20 درجة، اختيار ومقالي، ويغطي النحو والبلاغة والقراءة والنصوص والفصل الأول من القصة.
راجع المحتوى مع مدرس المادة، وحدد اسم القصة والنصوص المقررة قبل فتح الامتحان.

شكل الملف (مثال هيكلي مختصر؛ لا يُقبل للنشر لأنه ليس 20 سؤالًا):
```json
{
  "title": "امتحان اللغة العربية — ثانية بكالوريا",
  "version": "2026-term1-v1",
  "durationSeconds": 1800,
  "maxAttempts": 3,
  "totalMarks": 20,
  "reviewed": false,
  "reviewedBy": "",
  "reviewedAt": "",
  "questions": [
    {"id":"q1","topic":"النحو","type":"mcq","text":"نص السؤال المعتمد","marks":1,"options":["أ","ب","ج","د"],"correctIndex":0},
    {"id":"q2","topic":"القصة","type":"essay","text":"سؤال من الفصل الأول المعتمد","marks":1,"rubric":"الإجابة النموذجية وتوزيع الدرجة"}
  ]
}
```
القيم المسموحة للموضوع: النحو، البلاغة، القراءة، النصوص، القصة.
مفاتيح التصحيح والمقالي تبقى في Firestore خلف وظائف الخادم؛ لا تضع ملف الامتحان الحقيقي في استضافة GitHub Pages أو مستودع عام.
اختبارات البرمجة تستخدم أسئلة اصطناعية للتأكد من الحسابات، ولا تمثل محتوى منهج أو امتحانًا للطلاب.
